### 🎛️ what I'm into lately

- **Motion that means something.** Springs over easings. Interruptible over pretty.
- **Design systems that engineers actually use.** Tokens in, drift out.
- **Prototyping in real code.** Faster feedback. Fewer "wait, how does this work?" meetings.
- **AI in the design loop.** Using it to go from idea to working thing in an afternoon.
